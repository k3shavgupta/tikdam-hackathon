# Tikdam UI prototype

A local, throwaway interaction study. No Meta or partner credentials are used. No tax decisions are implemented. Only purchase price × business-use share is calculated.

Run from this folder:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173. Switch layouts with the bottom picker or keys 1–3. `?view=conversation`, `?view=guided`, and `?view=worksheet` link directly to each direction. A single user choice has not yet been made.

See UX-PLAN.md for the design question, journey, visual system, scope, and next decisions. No Git repository or implementation issue exists here, so the exploration is retained locally in this explicitly named prototype folder.
